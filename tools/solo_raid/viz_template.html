① 지금 몇 %면 최종 몇 %?

같은 점수라도 뒤에 들어오는 사람에게 밀려 %가 내려간다. 모델(여러 시즌 % 변환)의 「최종 % ÷ 지금 %」 배율로 바꾼다. 시점은 챌린지 시작 기준 — 1일차는 05:00 KST에 시작해 다음 날 04:59까지다. 배율은 지금 %와 상관없이 시점에만 달려 있다(모델 가정).

넣으면 일차 대신 실제 날짜로 보인다 (챌린지 시작 05:00 KST 기준, 비우면 일차 표기)
시즌 수준
지금 % 이면 → 최종
최종 % 안에 들려면 → 지금

최종 1·3·10%가 되는 「지금 %」

선 = 모델 중앙값, 띠 = 80% 구간(시즌 안 잡음 + 시즌 간 수준 차이). 시작 3시간 안은 관측이 없어 그리지 않았다. 점 = 실제로 그 최종 % 근처(±30%)로 끝난 사람이 그 시각에 보인 %. 세로축은 로그 눈금이고 위로 갈수록 상위다.

근거: 실제 관측의 「최종 % ÷ 그때 %」

점 하나 = 사람 하나의 하루치(같은 점수로 진행 중 %와 끝난 뒤 %를 둘 다 아는 경우). 옅은 점은 시각 등급 C(실제로는 더 이른 시각일 수 있음). 회색 계단 = 기준선 1(지난 시즌 일차별 중앙 배율).

값 = 그 시각에 이 % 안이면 최종 1·3·10% 안에 든다는 모델 중앙값, 괄호 = 80% 구간.

② 예측 정확도 — 시즌 하나씩 빼고 맞히기

나머지 시즌으로 prior를 만들고, 맞힐 시즌은 T시간까지 올라온 자료만 써서 최종 컷을 예측했다.

시즌 지점
예측(중앙) 80% 구간 95% 구간 실제 최종 컷 허용 오차(1·3% ±2%, 10% ±3%)

채운 점 = 허용 오차 안, 빈 점 = 밖. 예측 등급: A 보통 · B 주의 · C 강한 주의 · D 숫자만 참고(근거 없음). 12시간은 성공 판정(18~96시간)에서 뺀다.

시점별 오차 — 시즌 겹쳐 보기

±12% 밖 값은 가장자리에 붙여 그렸다. 정답 근거가 부족한 시즌·지점은 선이 없다.

|오차| = 시즌별 오차 절댓값의 중앙값. 기준선 1 = 지난 시즌 일차별 평균 수렴 비율로만 나눈 값. ✓ = 「쓸 만함」(시즌 2/3 이상이 허용 오차 안). 한섭은 저장된 검증 요약 그대로, 일섭·글섭은 같은 도구(xval.summarize)로 서버만 바꿔 계산했다.
