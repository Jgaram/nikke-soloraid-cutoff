# 글 숫자 주장 분류 지시문 (4단계 기간 실행)

세션 B 시범 지시문(`text_classify_prompt.md`)을 기간 실행용으로 고친 틀이다 (세션 F1, 2026-10-15).
`text_prep.py`가 `{SEASON_DESC}`를 채워 실행 폴더에 `text_prompt.md`로 쓰고, Workflow가 `{IN}`·`{OUT}`을 준다.
분류 기준은 S41 재수집 `prompts/text.md`의 `kind` 정의와 같다.

---

너는 「승리의 여신: 니케」 솔로 레이드 {SEASON_DESC} 커뮤니티 글에서
코드가 이미 뽑은 숫자(상위 % · 점수 억)가 어떤 종류의 주장인지만 고른다. 숫자를 고치거나 새로 찾지 않는다.

입력 `{IN}` (JSONL, Read로 한 번 읽는다): 한 줄에 하나 — `id`, `t`(글 시각), `title`, `body`(본문 앞 500자),
`src`(숫자가 나온 칸: title·body), `seg`(숫자가 든 문장 조각), `pct`, `score_eok`.

`kind`는 다음 중 하나:
- `self`: 글쓴이 자기 기록·순위. 자기 값을 넣어 묻는 질문("지금 0.5퍼면 1퍼 되나?")도 self.
- `cutoff`: 특정 구간 커트라인이 얼마라는 관측·전언 ("3퍼컷 255억", "250억이 3퍼래").
- `other`: 남의 기록·랭킹 상위권 전언.
- `predict`: 예상·추측 ("~일 듯", "~나올 거 같음", 계산기·모의전 값).
- `question`: 묻기만 함 — 숫자가 질문 속 가정이면 이것.
- `prev_season`: 지난 시즌 수치.

모든 줄을 본 뒤 `{OUT}`에 JSONL로 한 번에 쓴다 (Write 도구). 한 줄에 `{"id": 0, "kind": "self"}`. 입력 줄마다 한 줄.
마지막 답변은 한 줄만: `ok 줄=..`.
