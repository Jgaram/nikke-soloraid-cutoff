# nikke-soloraid-cutoff

승리의 여신: 니케 **솔로레이드 커트라인(1·3·10%)** 을 커뮤니티에 공개로 올라온 순위 화면에서 모아 예측하는 도구와 방법이다.

- **웹:** <https://jgaram.github.io/nikke-soloraid-cutoff/>
  - 진행 중 시즌 예측: 시점마다 갱신된다.
  - 지난 시즌 컷: 시즌별 최종 1·3·10% 컷이다.
  - [분석 페이지](https://jgaram.github.io/nikke-soloraid-cutoff/analysis.html): 지금 몇 %면 최종 몇 %가 되는지 계산하고, 지난 시즌으로 잰 예측 정확도를 보여 준다.
- 서버는 한섭·일섭·글섭을 다룬다. 시각은 모두 한국 시간(KST)이다.
- 게임사와 관계없는 비공식 프로젝트다.

## 들어 있지 않은 것

이 레포에는 **코드와 방법만** 있다. 수집한 자료는 비공개 레포에 따로 둔다.

- 글 원문, 사진, 닉네임, 원글 주소와 글 번호는 공개하지 않는다. 글과 사진은 올린 사람의 것이고, 랭킹 화면에는 다른 플레이어의 닉네임이 찍혀 있다.
- 웹에는 숫자와 개수만 싣는다. 근거는 「커뮤니티 N건」(그 시즌에 쓴 관측 수)으로만 적는다.
- 문서에 있는 데이터 경로(`data/solo-raid/...`)와 실험 기록 링크는 비공개 레포를 가리킨다. 공개하지 않는 파일로 가는 링크는 글자만 남겼다.
- **시험 시즌**의 정답 컷은 공개하지 않는다. 예측 방법을 정직하게 검증하려고 따로 떼어 둔 시즌이다(`data/solo-raid/split.json`). 웹에는 「잠김」으로 나온다.

도구를 직접 돌리려면 자기 자료를 모아야 한다. 이때 `docs/community-access.md`의 「공통 원칙」을 지킨다.

- robots.txt가 막은 주소는 요청하지 않는다.
- 자기 이름의 User-Agent를 쓰고, 브라우저로 위장하지 않는다.
- 요청 빈도는 낮게 유지하고, 403·429가 나오면 멈춘다.
- 모은 글을 AI 모델 학습에 쓰지 않는다.

## 갱신

비공개 레포가 정본이다. 그쪽 `main`에 push가 있을 때마다 GitHub Actions가 공개할 파일만 골라 이 레포(`main`)와 웹(`gh-pages`)으로 복사한다. 이 레포에 직접 커밋하면 다음 복사 때 덮어써진다.
